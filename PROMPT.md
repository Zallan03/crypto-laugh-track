# PROMPT — Laugh Track: The Crypto Trading Joke Contest

Build a make.fun entry for [Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a) from scratch in this session.

- Task: one line, max 200 chars; program writes `/output/entry.txt`.
- Judge criteria, most important first:
  1. One-line joke about crypto/trading life, clear setup + turn.
  2. Real laugh: surprise turn, payoff that rewards the setup.
  3. True to trading life: recognisable detail (chart, bag, group chat).
  4. Every word earns its place; tight phrasing, punchline at the end.
  5. Holds up on a second read; a line a trader would repeat to a friend.

- Text/image is everything that is judged. Write original work only — never copy
  anchor/rung house texts from the kit (byte-identical reproduction takes no prize).
- main.ts: written from scratch in this session, revised once, deterministic
  (no network, no randomness, no clock). Test twice to different output dirs;
  outputs must be byte-identical.
- Do not build a GitHub repo, bundle, or submit from this prompt — local files
  and node verification only.
